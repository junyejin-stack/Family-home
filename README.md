# 🏠 우리 가족 HOME

가족을 위한 작은 생활 대시보드입니다. 아이폰·태블릿 브라우저에서 바로 열 수 있는 **단일 파일 웹앱**(`index.html`)이고, 데이터는 이 기기(localStorage)에 저장되면서 **Firebase Realtime Database**로 가족 모두에게 실시간 동기화됩니다.

- 주소: https://junyejin-stack.github.io/Family-home/
- 화면·문서에는 아이 이름, 학교명, 학년·반을 적지 않습니다. (검색엔진에는 `noindex` 메타태그로 노출을 막습니다.)

## 탭 구성

| 탭 | 내용 |
|---|---|
| 🏠 홈 | 게임시간 잔액, 오늘 사용량, 다음 학원, 오늘 일정, 오늘 급식 요약 |
| 🎮 게임 | 게임시간 통장 — 시간 꺼내 쓰기(10·30분·직접 입력·타이머), 부모 인센티브 적립, 입출금 내역 |
| 📅 시간표 | 주간 학원 시간표, 학원 추가·삭제(부모 모드) |
| 🌙 저녁약속 | 월간 달력 + 날짜별 일정, 엄마/아빠/함께 × 저녁약속·야근·가족일정·기타, **일정 겹침 경고** |
| 🍱 학교 | 오늘·이번 주 급식(나이스 Open API), 알림장 |
| ⚙️ 설정 | 부모 PIN 변경, JSON 백업·복원, 실시간 동기화 상태 |

## 시작하기

1. 위 주소를 사파리로 열고 **홈 화면에 추가**합니다.
2. 사용자를 `👦 자녀`로 두고 쓰면 됩니다. 게임시간은 기본 **150분**에서 시작합니다.
3. 부모 기능(인센티브 적립, 학원·일정 등록, 알림장 작성, PIN 변경)은 상단 사용자에서 **엄마/아빠**를 고른 뒤 PIN을 넣으면 열립니다.
   - **기본 PIN은 `0000`** 입니다. 설정 탭에서 꼭 바꿔 주세요.

## 게임시간 규칙

- 하루 기본 지급 시간은 **0분**이고, 적립한 시간은 다음 날로 이월됩니다.
- 자녀 모드에서는 **꺼내 쓰기만** 가능하고, 적립·수정은 부모 모드에서만 됩니다.
- 타이머는 실제 사용한 시간(분 단위 올림)만큼만 차감하고, 잔액을 넘겨 쓸 수 없습니다.

## 급식 데이터

- 나이스 교육정보 개방 포털 Open API(`mealServiceDietInfo`)를 키 없이 호출합니다.
- 교육청·학교 코드는 `index.html`의 `SCHOOL` 설정 값만 사용하고, 화면과 이 문서에는 학교명을 적지 않습니다.
- API가 막히거나 데이터가 없으면 안내 문구와 함께 `새로고침`, 나이스 급식 정보 링크를 보여 줍니다.

## 알림장 자동 불러오기

같은 폴더의 `notices.json`을 자동으로 읽습니다. 학교나 학급에서 내려받은 알림장을 아래 형식으로 두면 앱에 표시됩니다.

```json
{
  "notices": [
    { "date": "2026-11-17", "title": "받아쓰기 12회 시험", "body": "수요일 3교시 · 준비물: 연필", "author": "담임" }
  ]
}
```

부모 모드에서는 앱 안에서 직접 알림장을 쓰거나 붙여넣을 수도 있습니다.

## 데이터 백업 · 실시간 동기화

- 게임시간 통장(잔액·내역), 학원 시간표, 저녁약속 일정, 알림장, 부모 PIN은 **Firebase Realtime Database**(프로젝트 `our-family-home-bc818`, 리전 `asia-southeast1`)의 `family` 노드에 저장됩니다. 한 기기에서 고치면 다른 기기에 **새로고침 없이** 바로 반영됩니다.
- 로그인 없이 읽기·쓰기가 되는 가족 전용 데이터베이스입니다(규칙: `family` 노드만 `read/write: true`, 그 외 차단). 아이 이름·학교명은 저장하지 않습니다.
- 인터넷이 끊기면 이 기기(localStorage)에 먼저 저장되고, 연결되면 자동으로 다시 맞춰집니다. 화면 상단에 `실시간 동기화 연결됨` / `오프라인` 상태가 표시됩니다.
- 기기 저장소는 그대로 남아 있어, 설정 → `JSON 내보내기`로 백업하거나 `JSON 가져오기`로 복원할 수 있습니다.
- 처음 연결할 때 클라우드가 비어 있으면 그 기기의 데이터가 그대로 올라갑니다. 이미 다른 기기가 올린 데이터가 있으면 클라우드 데이터가 기준이 됩니다.
